# Rock Paper Scissors Game

A simple Rock Paper Scissors game built with Python. The player chooses Rock, Paper, or Scissors, while the computer makes a random choice and the program determines the winner.

## How It Works

The player chooses one of three options:

- Rock
- Paper
- Scissors

The computer randomly selects one of the three options.

The winner is determined using these rules:

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- If both choose the same option, it is a draw

## Features

- Player vs. computer gameplay
- Random computer choices
- Automatic winner detection
- Draw detection
- Interactive user input
- Simple command-line interface
